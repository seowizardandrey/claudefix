# Claude Code Proxy & Auto-Patcher для Windows (GOST Edition)

Комплексное решение для стабильной и безопасной работы **Claude Code** (расширения для VS Code и автономной консольной утилиты Claude CLI) на операционных системах **Windows 10 / 11 / Windows Server** в условиях региональных ограничений.

Решение использует автономный Go-бинарник **GOST (`gost.exe`)**, нативный C# инсталлятор **`setup.exe`** и микро-враппер **`claude_wrapper.exe`**.

---

## 🎯 Ключевые возможности

1. **Нативный установщик `setup.exe` (Zero Dependencies)**:
   - Скомпилированный C# исполняемый файл.
   - **Не зависит** от политик PowerShell `ExecutionPolicy` («файл не имеет цифровой подписи») и флагов Mark of the Web.
   - Поддерживает запуск двойным кликом (интерактивный ввод) или через параметры командной строки.

2. **Мультитенантность и изоляция пользователя**:
   - Установщик настраивает службы и патчит окружение **исключительно для текущего пользователя**, из-под которого он запущен.
   - Каждый пользователь получает свой изолированный локальный порт (расчет по RID: `19000 + (RID - 1001)`) и персональную службу в Планировщике Задач.
   - Переменные `HTTP_PROXY` и `HTTPS_PROXY` устанавливаются **только внутри процесса Claude** и не затрагивают другие приложения ОС.

3. **Служба GOST и автозапуск до входа по RDP**:
   - Прокси-мост запускается через Windows Task Scheduler от имени **`NT AUTHORITY\SYSTEM`** с триггером **`AtStartup`** (при старте ОС).
   - Мост гарантированно поднимается сразу после перезагрузки удаленного сервера еще до того, как пользователь подключится по RDP.

4. **Встроенный бинарник `gost.exe`**:
   - Автономный бинарник GOST v3 включен непосредственно в пакет. Никаких внешних скачиваний на сервере не требуется.

5. **Белый список тяжелых хабов (Destination Bypass)**:
   - Ресурсы разработки идут напрямую в обход SOCKS5:
     - `github.com`, `*.github.com`, `gitlab.com`
     - `registry.npmjs.org`, `pypi.org`, `crates.io`, `nuget.org`
     - `docker.io`, `ghcr.io`, локальная сеть (`127.0.0.1`, `192.168.0.0/16`) и домены `.ru` / `.рф`.

## 🚀 Быстрый старт на Windows

### ⚡ Вариант 1: Однострочная веб-установка (PowerShell One-Liner) — ⭐ Рекомендуемый
> **Без красных экранов SmartScreen и без Mark of the Web!** 
> Скрипт скачивается напрямую консолью PowerShell, благодаря чему Windows не прикрепляет к файлам интернет-маску.

Откройте PowerShell и вставьте одну команду:
```powershell
irm https://raw.githubusercontent.com/seowizardandrey/claudefix/main/windows/install.ps1 | iex
```
*(Или с передачей параметров прокси сразу: `& ([ScriptBlock]::Create((irm https://raw.githubusercontent.com/seowizardandrey/claudefix/main/windows/install.ps1))) -Proxy "socks5://USER:PASSWORD@HOST:PORT"`)*.

Скрипт автоматически:
1. Скачает актуальные подписанные компоненты в защищенную директорию без интернет-метки;
2. Настроит системную службу автозапуска моста GOST в Планировщике Задач;
3. Пропатчит расширение Claude в VS Code, CLI и GUI;
4. Создаст ярлык `Claude Proxy Manager` на Рабочем столе и запустит монитор в системном трее.

---

### 📦 Вариант 2: Официальный Windows Installer (.MSI)
> Полноценный установочный пакет Microsoft Windows Installer с регистрацией в «Установка и удаление программ» (Programs and Features), иконкой и автоматическим созданием ярлыков.

1. Скачайте **[`ClaudeProxySetup.msi`](ClaudeProxySetup.msi)** из каталога `windows/`.
2. Запустите двойным кликом стандартный мастер установки Windows Installer.
3. Программа установится в `C:\Program Files\Claude Code Proxy`, добавит путь в системный `PATH` и разместит ярлыки в меню «Пуск» и на Рабочем столе.

---

### 📁 Вариант 3: Автономный установщик `setup.exe` или `install.cmd`
Если репозиторий уже склонирован через `git clone`:
```cmd
setup.exe "socks5://USER:PASSWORD@HOST:PORT"
```
*(Либо запустите `install.cmd` двойным кликом без параметров — он автоматически снимет блокировки с файлов и запросит адрес прокси).*

## 🔏 Цифровая подпись Authenticode (Code Signing)
Все исполняемые бинарники, установщик и скрипты подписаны персональной цифровой подписью разработчика:
* **Издатель**: `CN=Andrey Sokolov, O=Claude Code Proxy, E=seowizard.andrey@gmail.com`
* **Сайт проекта**: `https://github.com/seowizardandrey/claudefix`
* **Алгоритм**: SHA-256 с точной временной меткой **RFC 3161 Timestamp (DigiCert)**
* **Подписанные файлы**: `ClaudeProxySetup.msi`, `ClaudeProxyPatcher.exe`, `setup.exe`, `claude_wrapper.exe`, `install.ps1`, все вспомогательные `.ps1` скрипты.

### Шаг 1: Запустите установку

Запустите командную строку от имени **Администратора** в папке `windows`:

```cmd
setup.exe "socks5://USER:PASSWORD@HOST:PORT"
```
*(Или запустите `setup.exe` двойным кликом без параметров — установщик вежливо запросит адрес SOCKS5 в консоли).*

Также можно воспользоваться батником:
```cmd
install.cmd "socks5://USER:PASSWORD@HOST:PORT"
```

#### Что произойдет автоматически:
1. Общесистемный бинарник `gost.exe` разместится в `C:\ProgramData\claude-proxy\bin\gost.exe`.
2. В профиле текущего пользователя (`%USERPROFILE%\.config\claude-proxy\`) запишется персональная конфигурация `proxy.env` и `bypass.conf`.
3. В Планировщике Задач Windows зарегистрируется служба `ClaudeProxy_<Username>` с триггером `AtStartup` (SYSTEM).
4. Прокси-мост запустится немедленно на персональном порту (по умолчанию `127.0.0.1:19000`).
5. Пропатчится расширение Claude Code в VS Code текущего пользователя (`claude.exe` -> `claude.real.exe` + `claude_wrapper.exe`).
6. Папка утилит добавится в пользовательский `PATH`.

## 💻 Проверка и управление

### 1. Проверка статуса службы:
```cmd
status.cmd
```
Показывает, слушает ли мост локальный порт и активна ли задача в Task Scheduler.

### 2. Запуск Claude Code в терминале:
```cmd
claude --version
claude -p "ping"
```

### 3. В редакторе VS Code:
Откройте VS Code под вашим пользователем. Расширение Claude Code сразу подключится через локальный изолированный мост.

### 4. Остановка и запуск моста:
```cmd
stop.cmd
start.cmd
```

---

## 🗑 Удаление

Чтобы полностью удалить службу прокси-моста, восстановить все оригинальные бинарники Claude Code и вернуть систему в исходное состояние:

```cmd
setup.exe --uninstall
```
*(Или запустите `uninstall.cmd`).*
